# Innovation Points

1. **Evidence-first context engineering**: Context is selected by artifact provenance, not simply by recency or text similarity.
2. **Negative evidence is preserved**: Invalid citations and unlinked experiment claims become explicit rejected records instead of disappearing from the trajectory.
3. **Budget with provenance retention**: Long claims are truncated within a context budget while DOI, URL, or artifact path remains intact.
4. **Reproducibility as an executable output**: The same workflow emits a machine-readable ledger and resource report, enabling paper claims to be audited against raw inputs and run metadata.
